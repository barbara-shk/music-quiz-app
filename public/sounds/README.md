# Sound Files

## Required Sound

### reveal.mp3
This file is played when the game master reveals the correct answer.

**Where to get a celebration sound:**
- [freesound.org](https://freesound.org/) - Search for "celebration", "success", or "fanfare"
- [Zapsplat](https://www.zapsplat.com/) - Free sound effects
- Create your own using online tools

**Requirements:**
- Format: MP3
- Duration: 2-5 seconds recommended
- Name: `reveal.mp3`
- Place in: `public/sounds/reveal.mp3`

**Example searches:**
- "short fanfare"
- "success sound"
- "celebration chime"
- "victory sound effect"

Once you download a sound file, rename it to `reveal.mp3` and place it in this directory.
